3. NUEVO SISTEMA DE FAUNA (SistemaFauna.cs - 200+ líneas)
   
   Características principales:
   ✓ Instantiación de 6 tipos de animales rigged
   ✓ Distribución natural en 4 zonas forestales (norte, sur, este, oeste)
   ✓ Culling por distancia (LOD) configurable
   ✓ Patrullaje aleatorio simple para animales cercanos
   ✓ Pool de instancias con reutilización
   ✓ Fallback procedural (cápsula básica) si falta prefab
   
   Tipos de fauna soportados:
   • Caballo rigged (herbívoro, común) - riggedHorse.blend
   • Lobo (depredador, raro) - Wolf.zip
   • Conejo (pequeño herbívoro) - rabbit.blend
   • Pollo (ave domesticada) - chicken.zip
   • Gallo (ave) - rooster.zip
   • Oveja (herbívoro) - sheepies.blend
   
   Distribución inteligente:
   - Herbívoros comunes (caballos 40%, ovejas 40%, conejos 20%)
   - Aves en bordes de zonas (pollo 50%, gallo 50%)
   - Depredadores raros (lobo <10% de fauna)
   
   Beneficios:
   - Escena mucho más viva y orgánica
   - Movimiento genera dinamismo
   - Perfecto para contexto de manifestación (animales afectados por situación)
   - Fácil expansión a nuevos tipos

4. INTEGRACIÓN EN SistemaAssets.cs
   
   Cambios:
   ✓ Nueva función CargarPrefabsDescargas() para cargar arrays de prefabs
   ✓ PropagarAssets() ahora llama a AsignarPrefabsDescargas() en todos los sistemas
   ✓ Soporte para múltiples rutas de Downloads
   ✓ Carga automática de prefabs con patrón glob/matching
   
   Flujo de carga:
   1. SistemaAssets carga prefabs de E:\assets (default)
   2. Luego carga prefabs de Assets/Downloads/{categoria}/
   3. Propaga a cada sistema via AsignarPrefabsDescargas()
   4. Cada sistema integra en su lógica de spawning

🚀 CÓMO ACTIVAR LAS MEJORAS:
──────────────────────────────────────────────────────────────────────────────

1. En Unity, abre ESCENA_ALSASUA
2. Configura la ruta de Downloads: Alsasua → 📦 Configurar Ruta de Downloads
3. Descomprime los archivos .7z/.zip en C:\Users\{usuario}\Downloads
4. Importa los assets: Alsasua → 📦 Importar Downloads - Recomendados
5. Autoconecta: Alsasua → 📦 Autoconectar Assets Importados
6. Presiona Play

RESULTADO: Escena completamente transformada visualmente

💾 FALLBACKS Y COMPATIBILIDAD:
──────────────────────────────────────────────────────────────────────────────

✓ Cada sistema mantiene fallback procedural
  • SistemaVegetacion: Si faltan plantas, genera árboles procedurales
  • SistemaEdificios: Si faltan edificios, genera cubos texturados
  • SistemaFauna: Si faltan animales, simplemente no spawnea

✓ Zero hard dependencies
  • Los sistemas funcionan sin los assets nuevos
  • Degradación elegante (siempre hay contenido visual)
  • Perfect para build para PC menos potentes
